# App by Admiral Andrewha and Claude Code

**Finance Auditor** — минималистичный учёт расходов и доходов для узкого круга пользователей.
Работает на телефоне и ПК, ставится на главный экран как PWA.

## Возможности

- Быстрое добавление операции: кнопка «+» → сумма → тап по категории (запись сохраняется сразу)
- Редактирование и удаление (удаление можно отменить из уведомления)
- Предустановленные категории с иконками; свои категории, цвета, скрытие
- Периоды: день, неделя, месяц, год, произвольный диапазон; листание стрелками
- Дашборд: расходы, доходы, баланс, кольцевая диаграмма по категориям, расходы по дням или месяцам
- Месячный лимит и лимиты по категориям с прогрессом и подсказкой «≈ сколько можно тратить в день»
- Список операций: фильтр по типу и категориям, сортировка, поиск по комментарию
- Вход по логину и паролю, «вечная» сессия, выход на всех устройствах
- Светлая, тёмная и системная тема, сиреневый акцент

## Стек

Next.js 16 (App Router, Server Actions) · TypeScript · Tailwind CSS v4 · shadcn/ui (Radix) · Recharts ·
SQLite (better-sqlite3) + Drizzle ORM · argon2id

## Запуск

```bash
npm install
cp .env.example .env
npm run dev        # http://localhost:3000/finance-auditor
```

Деплой на сервер описан в [DEPLOY.md](DEPLOY.md).
